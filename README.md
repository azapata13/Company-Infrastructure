# Company Infrastructure

Durable technical memory and implementation repository for the company's internal systems.

The name is intentionally neutral because the business name is expected to change.

## Target stack

- Slack = operational cockpit
- Odoo = future ERP / CRM / sales / finance core
- NetSuite = legacy/reference + migration source
- n8n = orchestration/automation
- Google Drive = documents
- Gmail / Google Workspace = communications
- WooCommerce = ecommerce channel
- Central observability = logs/audit/costs
- AI router = cost-aware model selection
- GitHub + Codex = implementation workflow
