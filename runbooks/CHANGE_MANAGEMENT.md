# Change Management

Before a production-impacting change:

1. Define change.
2. Identify affected systems.
3. Read current state.
4. Check prior/concurrent work.
5. Confirm permissions.
6. Define rollback/recovery.
7. Assign correlation ID.
8. Obtain approval if required.
9. Execute.
10. Verify.
11. Log.
12. Update docs/state.

For sensitive changes, retain approval identity and before/after state where feasible.
